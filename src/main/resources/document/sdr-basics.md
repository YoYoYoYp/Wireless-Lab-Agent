# SDR基础

## 软件无线电

软件无线电把调制、解调、滤波、同步和频谱分析等传统硬件功能尽量放到可编程软件中。USRP 负责射频收发、模数转换和高速数据传输，主机程序负责基带算法与实验编排。

## IQ 采样

复基带信号由同相分量 I 和正交分量 Q 表示。采样率决定可观察的瞬时带宽；设置中心频率后，IQ 数据描述中心频率附近的基带频谱。采样率、主机吞吐量和 USRP 链路能力需要同时满足，否则可能出现 overflow 或 underflow。

## BPSK、QPSK、16-QAM 与 2-FSK

- BPSK 每个符号携带 1 bit，星座点间距大，抗噪声能力强，适合较低 SNR。
- QPSK 每个符号携带 2 bit，频谱效率更高，但对相位同步更敏感。
- 16-QAM 每个符号携带 4 bit，吞吐率更高，对 SNR、增益和同步精度要求也更高。
- 2-FSK 用两个频率表示二进制状态，对相位误差不敏感，适合基础文本收发验证。

## 自适应调制

自适应调制先用探测包估计链路质量，再在可靠性与频谱效率之间选择调制方式。项目控制器采用的示例决策为：SNR 小于 -18 dB 使用 BPSK；-18 dB 到 -15 dB 使用 QPSK；高于 -15 dB 使用 16-QAM。阈值必须结合真实设备、带宽和接收算法重新标定。

## 底噪、扫频与认知选频

底噪是接收机在没有目标信号时观察到的背景功率。扫频工具在候选频点采集 IQ 数据并计算接收功率；认知选频比较多个候选点，选择接收功率较低、干扰较少的频点，再执行 Tone 或文本传输。单次功率最低不等于长期可用，实验应重复采样并遵守频谱管理要求。

故障排查、UHD 错误码和性能问题统一收录在“故障诊断”类文档，避免把运行时故障与基础原理混成同一检索类别。
